# 식장산 힐링 전망대

대전 식장산 식장루에서 바라보는 하늘을 온라인으로 옮긴 힐링 공간입니다.
실제 시각에 맞춰 해가 뜨고 지며, 달의 모양과 위치, 별자리가 식장산 좌표 기준으로 계산되어 움직입니다.

## 바로 보기

**https://sikjangsan-healing.onrender.com** (Render 무료 요금제 — 15분 동안 방문이 없으면 잠들어 첫 접속이 30초~1분 걸리고, 풍등·방명록은 서버가 다시 켜질 때 초기화돼요)

## 실행

이 폴더(`식장산힐링전망대`)에서:

```bash
node serve.js
```

브라우저에서 http://localhost:5173 을 엽니다. (빌드 과정이나 설치할 패키지가 없습니다.)

## 기능

- **24시간 실시간 하늘** — 해·달 위치, 달의 위상, 별(밝은 별 30여 개 + 배경 별, 은하수)이 실제 천문 계산으로 움직임
- **대전 풍경** — 서쪽 대전 도심 야경(불빛이 해 질 녘부터 하나둘 켜짐, 도로 위 차량), 계룡산·보문산·계족산 등 지명, 식장루와 송신탑
- **실제 날씨** — Open-Meteo에서 식장산 현재 날씨를 받아 구름·비·눈·안개를 표현 (15분마다 갱신)
- **계절** — 달에 따라 산 빛깔이 바뀜 (봄·여름·가을 단풍·겨울)
- **시간 여행** — 하루 중 원하는 시각으로 이동, 60×~3600× 빠르게 흘려보기, 일출·일몰 바로가기
- **소리** — 바람·새소리·빗소리·풀벌레·부엉이 (Web Audio로 합성, 음원 파일 없음). 끄기 전까지 이음새 없이 계속 흐르고, 켜 둔 채 떠나면 다음 방문 때 화면을 한 번 누르는 순간 이어서 흐름
- **클래식 음악** — 사티 짐노페디 1번, 바흐 프렐류드 C장조, 파헬벨 캐논, 브람스 자장가, 모차르트 작은 별 변주곡 주제, 베토벤 엘리제를 위하여. 저작권이 끝난 악보를 페이지가 직접 연주(피아노·오르골·하프 음색). 이어 듣기/한 곡 반복, 잠들기 타이머(15·30·60분). `music/` 폴더에 퍼블릭 도메인 음원을 넣으면 '내 음악'으로 추가 (`music/README.md` 참고)
- **숨 고르기** — 4초 들숨, 2초 멈춤, 6초 날숨 호흡 안내
- **방명록** — 이름(선택)과 한 줄 마음을 남기면, 남긴 시각의 하늘(새벽·낮·노을·밤)과 함께 저장되고 다른 방문자 화면의 하늘에도 잠시 떠오름. 같은 사람은 30초에 한 번, 글은 140자까지
- **함께 보는 사람 수** — "지금 12명이 함께 식장산 하늘을 보고 있어요". 새 사람이 들어오면 살짝 알림. 창마다 25초 간격으로 신호를 보내고 90초 안에 신호가 온 창을 셈 (서버 메모리에만 두고 저장·개인정보 수집 없음)
- **소원 풍등** — 소원(40자)을 적으면 풍등이 하늘로 올라감. 다른 사람이 24시간 안에 띄운 풍등도 대전 시내 위로 천천히 떠오름. 같은 사람은 20초에 한 번
- **하늘 소식** — 유성우(사분의자리·거문고자리·물병자리 에타·페르세우스·오리온·사자자리·쌍둥이자리) 기간엔 별똥별이 실제로 더 많이 떨어짐, 보름달·슈퍼문·삭, 춘분·하지·추분·동지 안내
- **계절 장면** — 봄 벚꽃잎(3/25~4/20), 여름밤 반딧불이(6/10~7/31), 가을 낙엽(10/10~11/25), 겨울 눈 덮인 능선(12/10~2월)
- **오늘의 한 줄** — 들어올 때 위로의 글귀 한 줄 (날마다 바뀌고, 같은 날엔 모두 같은 글귀)
- **마음 날씨** — 오늘 마음을 맑음·구름 조금·흐림·비·천둥·무지개로 남기고 달력으로 모아 보기 (이 브라우저에만 저장)
- **휴대폰** — 휴대폰으로 열면 아래 탭 막대(소리·음악·풍등·시간·더보기)와 아래에서 올라오는 시트로 자동 전환, 두 손가락 확대. 같은 와이파이에서 컴퓨터 주소로 접속(서버 시작 시 주소 표시), 홈 화면에 추가하면 앱처럼 열림
- **둘러보기** — 드래그로 360° 회전·하늘 올려다보기, 휠 확대, 키보드(←→↑↓, +−, H, L)

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조 |
| `css/style.css` | 스타일 |
| `js/astro.js` | 해·달 위치, 달 위상, 일출·일몰 계산 |
| `js/scene.js` | 하늘·별·산·도시를 캔버스에 그리는 렌더러 |
| `js/audio.js` | 자연의 소리와 음악 합성 |
| `js/main.js` | 시간 흐름, 조작, 날씨 연결 |
| `js/music.js` | 클래식 곡 악보·악기 음색·플레이어·잠들기 타이머 |
| `music/playlist.json` | 내 음악 목록 (직접 넣은 퍼블릭 도메인 음원) |
| `js/skyevents.js` | 유성우·보름달·절기 등 하늘 소식 |
| `js/comfort.js` | 오늘의 한 줄 |
| `js/lanterns.js` | 소원 풍등 (띄우기·다른 사람 풍등 받아오기) |
| `js/mood.js` | 마음 날씨 기록과 달력 |
| `js/mobile.js` | 휴대폰 화면의 탭 막대와 시트 |
| `manifest.webmanifest`, `icons/` | 홈 화면에 추가할 때 쓰는 앱 정보와 아이콘 |
| `사용설명서.html` | 사용설명서 (브라우저로 열기) |
| `js/presence.js` | 함께 보는 사람 수 (신호 보내기·표시) |
| `js/guestbook.js` | 방명록 글쓰기·목록·하늘에 띄우기 |
| `serve.js` | 로컬 서버 (정적 파일 + 방명록 `/api/guestbook` + 풍등 `/api/lanterns` + 접속 신호 `/api/presence`) |
| `data/guestbook.json` | 방명록 저장 파일 (첫 글을 남기면 생김, 최근 500개 보관) |
| `data/lanterns.json` | 풍등 저장 파일 (최근 1000개 보관) |
