# 내 음악 추가하기

이 폴더에 음원 파일(mp3, ogg 등)을 넣고 `playlist.json`에 등록하면 음악 패널의 **내 음악**에 나타나요.

```json
[
  { "title": "짐노페디 1번", "composer": "에릭 사티", "file": "gymnopedie-1.mp3", "license": "Public Domain" }
]
```

## 저작권 주의

곡(작곡) 자체는 저작권이 끝났어도, **녹음(연주)에는 연주자·음반사의 권리가 따로 있어요.**
반드시 녹음까지 퍼블릭 도메인(Public Domain, CC0)으로 공개된 파일만 쓰세요.

- **Musopen** (musopen.org) — 퍼블릭 도메인으로 공개한 클래식 녹음이 많아요. 파일마다 라이선스 표시를 확인하세요.
- **Wikimedia Commons** — 파일 페이지의 라이선스가 "Public domain" 또는 "CC0"인지 확인하세요. CC BY 계열은 출처 표시가 필요해요.

`license` 칸에 출처와 라이선스를 적어 두면 목록에 함께 보여요.
